# Contributing to Python for ML

Thank you for your interest in contributing to this Python for Machine Learning repository! 🎉

## How to Contribute

### Reporting Issues

If you find any bugs, typos, or have suggestions for improvements:
1. Check if the issue already exists in the [Issues](https://github.com/Abhinavexists/Python-for-ML/issues) section
2. If not, create a new issue with a clear title and description
3. Include steps to reproduce (if applicable)

### Submitting Changes

1. **Fork the Repository**
   ```bash
   git clone https://github.com/Abhinavexists/Python-for-ML.git
   cd Python-for-ML
   ```

2. **Create a Virtual Environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Create a New Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Your Changes**
   - Follow the existing code style and naming conventions
   - Use meaningful variable and function names
   - Add comments where necessary
   - Test your code before committing

5. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Description of your changes"
   ```

6. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Create a Pull Request**
   - Go to the original repository
   - Click "New Pull Request"
   - Select your branch
   - Provide a clear description of your changes

## Code Style Guidelines

### Python Files
- Follow PEP 8 style guidelines
- Use 4 spaces for indentation
- Maximum line length: 88 characters
- Use descriptive variable names
- Add docstrings to functions and classes

### Jupyter Notebooks
- Clear all outputs before committing
- Use markdown cells to explain concepts
- Keep code cells focused and concise
- Add comments in code cells

### File Naming
- Use snake_case for Python files: `my_module.py`
- Use descriptive names with underscores for notebooks: `Data_Manipulation.ipynb`
- Follow the numbering convention: `1.Introduction.ipynb`, `2.Advanced_Topics.ipynb`
